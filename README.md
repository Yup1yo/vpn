# Персональная подписка HAPP

Этот репозиторий каждый час:

1. загружает облегчённую публичную подборку `BLACK_VLESS_RUS_mobile.txt`;
2. удаляет повторяющиеся IP/домены и порты;
3. проверяет возможность TCP-подключения;
4. публикует 10 узлов с минимальной задержкой в `subscription.txt`.

Готовый Raw URL файла `subscription.txt` добавляется в HAPP как обычная
подписка. Источник конфигураций:
[`igareck/vpn-configs-for-russia`](https://github.com/igareck/vpn-configs-for-russia).

> Публичные бесплатные узлы не являются доверенными. TCP-проверка не заменяет
> полноценную проверку протокола внутри HAPP и не гарантирует доступность узла
> из сети конкретного оператора.
