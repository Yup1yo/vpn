# VPN-бот с персональными подписками Happ

Проект состоит из Telegram-бота, API персональных подписок и фонового
обновлятора VPN-конфигураций. Каждый пользователь получает отдельный URL,
который можно продлить, отозвать или перевыпустить независимо от остальных.

## Возможности

- пробный период при первом запуске;
- тарифы на 30, 90 и 365 дней;
- короткий персональный URL подписки Happ вида `https://vpn.example.com/TOKEN`;
- автоматическая блокировка после истечения срока;
- перевыпуск утёкшей ссылки;
- реферальные ссылки и бонусные дни;
- обращения в поддержку;
- админ-команды выдачи и отзыва доступа;
- внутренний API для будущего платёжного webhook;
- PostgreSQL в production и SQLite для локальной разработки;
- автоматическая проверка и отбор 15 обычных и 5 узлов для белых списков;
- синхронизация персональных подписок с GitHub-подборкой каждые 5 минут;
- Docker Compose, HTTPS и автоматические сертификаты Caddy.

## Важное ограничение

Сейчас персональные URL управляют доступом к общей подборке публичных узлов.
Это позволяет отдельно отключать клиентов, но сами VPN-учётные данные внутри
подборки остаются общими. Для коммерческого запуска нужно подключить собственные
VPS и создавать отдельный VLESS UUID для каждого клиента.

Публичные бесплатные узлы нельзя считать доверенными или гарантированно
доступными. Их допустимо использовать только для разработки и тестового тарифа.

## Безопасность токена Telegram

Если токен бота когда-либо был отправлен в переписку или опубликован, выполните
`/revoke` в `@BotFather` и создайте новый. Токен хранится только в `.env`.
Файл `.env` исключён из Git и Docker-контекста.

## Локальный запуск

1. Создайте окружение и установите зависимости:

   ```bash
   python -m venv .venv
   .venv/Scripts/pip install -r requirements-dev.txt
   ```

2. Скопируйте `.env.example` в `.env` и заполните новый `BOT_TOKEN`, свой
   Telegram ID в `ADMIN_IDS` и `INTERNAL_API_KEY`.
3. Запустите API:

   ```bash
   .venv/Scripts/uvicorn app.api:app --reload
   ```

4. Во втором терминале запустите бота:

   ```bash
   .venv/Scripts/python -m app.bot
   ```

## Запуск на VPS

1. Направьте DNS A-запись домена на IPv4 сервера.
2. Установите Docker Engine с Compose.
3. Создайте `.env` на основе примера. Дополнительно задайте случайный пароль:

   ```text
   POSTGRES_PASSWORD=длинный-случайный-пароль
   ```

4. Запустите:

   ```bash
   docker compose up -d --build
   ```

Caddy автоматически получит TLS-сертификат. В `PUBLIC_BASE_URL` должен быть
указан тот же адрес, например `https://vpn.example.com`.

## Админ-команды

- `/grant TELEGRAM_ID DAYS` — выдать или продлить доступ;
- `/week TELEGRAM_ID` — добавить 7 дней;
- `/month TELEGRAM_ID` — добавить 30 дней;
- `/revoke TELEGRAM_ID` — отозвать доступ;
- `/user TELEGRAM_ID` — показать пользователя;
- `/reply TELEGRAM_ID текст` — ответить на обращение.

Пользователь должен хотя бы один раз запустить бота, прежде чем администратор
сможет выдать ему доступ через Telegram-команду.

В админ-панели также есть список последних 30 клиентов, карточка подписки и
кнопки выдачи 7/30 дней и отключения доступа. После истечения срока персональный
URL возвращает HTTP 410 и больше не выдаёт VPN-конфигурации.

## Интеграция оплаты СБП/картой

Платёжный адаптер после подтверждённого webhook вызывает закрытый endpoint:

```http
POST /internal/subscriptions/grant
X-Internal-Key: <INTERNAL_API_KEY>
Content-Type: application/json

{
  "telegram_id": 123456789,
  "days": 30,
  "reward_referrer": true
}
```

Нельзя активировать доступ по возврату пользователя на страницу «Успешно».
Активация выполняется только после проверки подписи webhook конкретного
платёжного провайдера. Его адаптер добавляется после выбора банка или
эквайринга.

## Исходная тестовая подборка

Автообновлятор использует публичную подборку
[`igareck/vpn-configs-for-russia`](https://github.com/igareck/vpn-configs-for-russia),
удаляет повторяющиеся адреса, отбрасывает незашифрованные VLESS-подключения,
трижды проверяет TCP-доступность, отбрасывает нестабильные ответы и оставляет
15 обычных узлов и 5 резервных узлов для режима белых списков с минимальной
медианной задержкой.
