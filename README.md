# Персональная подписка HAPP

Этот репозиторий каждый час:

- загружает 10 обычных конфигураций из `BLACK_VLESS_RUS_mobile.txt`;
- добавляет 5 конфигураций для режима белых списков из `Vless-Reality-White-Lists-Rus-Mobile.txt`;
- оставляет только разные IP-адреса;
- дважды проверяет TCP-подключение к каждому узлу;
- сортирует доступные узлы по задержке и публикует их в `subscription.txt`.

Готовая ссылка для HAPP:

`https://raw.githubusercontent.com/Yup1yo/vpn/refs/heads/main/subscription.txt`

Источник конфигураций: [igareck/vpn-configs-for-russia](https://github.com/igareck/vpn-configs-for-russia).

> Публичные бесплатные узлы не являются доверенными. TCP-проверка показывает доступность адреса и задержку установки соединения, но не измеряет реальную скорость загрузки через VPN и не гарантирует работу из сети конкретного оператора. Белые списки предназначены для специальных ограничений внутри РФ.
