# Персональная подписка HAPP

Этот репозиторий каждый час:

- загружает обычные конфигурации из поддерживаемых публичных подборок;
- добавляет конфигурации для режима белых списков;
- отбрасывает незашифрованные VLESS-подключения и повторяющиеся адреса;
- четырежды проверяет TCP-подключение к каждому узлу;
- выбирает 15 обычных узлов и 5 узлов белых списков по минимальной медианной задержке;
- публикует результат в subscription.txt.

Готовая лента для сервиса:

https://raw.githubusercontent.com/Yup1yo/vpn/refs/heads/main/subscription.txt

Источник конфигураций: https://github.com/igareck/vpn-configs-for-russia.

> Публичные бесплатные узлы не являются доверенными. Проверка подтверждает доступность адреса и задержку TCP-соединения, но не может гарантировать реальную пропускную способность, работу из сети каждого оператора или постоянную доступность YouTube, Telegram и Discord. Белые списки предназначены для специальных ограничений внутри РФ.
